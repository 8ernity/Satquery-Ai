2. Authentication Suite Configuration

BHUVISION supports three enterprise authentication workflows: Google Single Sign-On (OAuth 2.0), Email/Password Registration, and Phone SMS OTP Verification.

2.1 Google OAuth 2.0 Setup

  1. Navigate to the Google Cloud Console (console.cloud.google.com) and create or select your project.
  2. Navigate to APIs & Services → Credentials and click Create Credentials → OAuth Client ID.
  3. Set Application Type to Web application.
  4. Under Authorized JavaScript origins, add your domains: 
    http://localhost:8000
http://127.0.0.1:8000
https://bhuvision.yourdomain.com
  5. Under Authorized redirect URIs, add: 
    https://bhuvision.yourdomain.com/api/auth/google/callback
  6. Copy your Client ID and Client Secret into your .env file: 
    GOOGLE_CLIENT_ID=your-google-client-id.apps.googleusercontent.com
GOOGLE_CLIENT_SECRET=GOCSPX-your-google-client-secret

2.2 Phone SMS OTP Integration

The platform includes endpoints for SMS dispatch (/api/auth/otp/send) and verification (/api/auth/otp/verify). By default, in local testing it uses secure simulated delivery. For production dispatch, configure your SMS Gateway provider (Twilio, AWS SNS, MSG91, or Fast2SMS): 

SMS_GATEWAY_PROVIDER=twilio  # options: twilio, aws_sns, msg91, fast2sms
TWILIO_ACCOUNT_SID=ACXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX
TWILIO_AUTH_TOKEN=your_twilio_auth_token
TWILIO_PHONE_NUMBER=+1234567890

4. Step-by-Step Deployment Workflows

Option A: Docker & Docker Compose (Recommended for Production)

Deploy the entire stack with containerized FastAPI backend, Nginx reverse proxy, and automated SSL: 

# 1. Clone repository on production server
git clone https://github.com/Ayushnot41/Satquery-Ai.git /opt/bhuvision
cd /opt/bhuvision

# 2. Configure production secrets
cp .env.example .env
nano .env  # Add your domain, JWT secret, and API keys

# 3. Build and launch containerized services
docker compose up -d --build

# 4. Verify running health
docker compose ps
curl -I http://localhost:8000/api/health

Option B: Linux Cloud VM (Ubuntu 24.04 LTS / AWS EC2 / DigitalOcean)

Deploy as a systemd service behind an Nginx reverse proxy: 

# 1. Install system prerequisites
sudo apt-get update && sudo apt-get install -y python3.13 python3.13-venv nginx certbot python3-certbot-nginx git

# 2. Setup project virtual environment
cd /opt/bhuvision
python3.13 -m venv venv
source venv/bin/activate
pip install --upgrade pip
pip install -r backend/requirements.txt

# 3. Configure Systemd Service (/etc/systemd/system/bhuvision.service)
sudo tee /etc/systemd/system/bhuvision.service << 'EOF'
[Unit]
Description=BHUVISION SatQuery AI FastAPI Application
After=network.target

[Service]
User=www-data
WorkingDirectory=/opt/bhuvision/backend
ExecStart=/opt/bhuvision/venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000 --workers 4
Restart=always

[Install]
WantedBy=multi-user.target
EOF

# 4. Start and enable service
sudo systemctl daemon-reload
sudo systemctl start ahuvision
sudo systemctl enable bhuvision

5. Nginx Reverse Proxy & SSL Configuration

Create an Nginx configuration block with HTTP/2, WebSocket proxying, and caching: 

server {
    listen 80;
    server_name bhuvision.yourdomain.com;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl http2;
    server_name bhuvision.yourdomain.com;

    ssl_certificate /etc/letsencrypt/live/bhuvision.yourdomain.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/bhuvision.yourdomain.com/privkey.pem;

    # Gzip Compression
    gzip on;
    gzip_types text/plain text/css application/json application/javascript text/xml;

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
# Issue free Let's Encrypt SSL Certificate
sudo certbot --nginx -d bhuvision.yourdomain.com

6. Mobile Web App (PWA) Deployment

BHUVISION is fully engineered as an installable Progressive Web App:

  • Web App Manifest: Hosted at /manifest.json with display: standalone, theme_color: #0B1120, and complete ISRO icon sets.

  • Google Play Store Packaging: Use Microsoft PWABuilder (pwabuilder.com) or Bubblewrap CLI to generate an Android signed .aab package directly from your live URL.
